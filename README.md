<u><strong>🔤 Python Spell Checker</strong></u>

A simple command-line Spell Checker built using Python and the "pyspellchecker" library. It detects misspelled words and automatically suggests corrections.

✨ Features

- Detects spelling mistakes
- Automatically corrects misspelled words
- Displays the corrections made
- Supports continuous text input
- Type "exit" to quit the application

🛠️ Technologies Used

- Python 3
- pyspellchecker
- Git & GitHub

⚙️ Installation & Usage

1. Clone the repository

git clone https://github.com/jatinkr1/Spell-Checker.git
cd Spell-Checker

2. Install dependencies

pip install -r requirements.txt

3. Run the program

python spell_checker.py

💻 Example

Enter text to check (or type "exit" to quit): I hav a beutiful day

Correcting "hav" to "have"
Correcting "beutiful" to "beautiful"

Corrected Text : I have a beautiful day
